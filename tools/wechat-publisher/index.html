WeChat Publisher

把 Markdown 文案转换为微信公众号草稿，辅助完成封面绑定、正文预检和上传检查。它负责提高稳定性，最终发布仍由人工确认。

适用场景

公众号文章已经定稿，需要把标题、摘要、正文、封面图和内文图稳定上传到草稿箱，减少手工复制、图片遗漏和格式错乱。

使用方式

  1. 准备 Markdown 正文、封面图、内文图和文章元信息。
  2. 运行本地脚本完成预检：标题、摘要、正文结构、图片引用。
  3. 创建或更新微信公众号草稿。
  4. 绑定封面并生成上传结果。
  5. 人工用手机预览，确认封面裁切、内文图和原创声明后发布。

边界

这是内部发布辅助工具，不开放自助使用。它不替代人工终审，也不自动点击最终发布按钮。

下一步补充

按水手勃勃建议，本周补一组前后对比图：Markdown 原文、公众号草稿预览、封面绑定状态和发布前检查结果。
