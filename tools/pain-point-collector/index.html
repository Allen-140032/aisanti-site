痛点评论采集助手

把公开评论里的真实抱怨、高频问题和需求信号整理成选题线索、工具机会和需求池。

适用场景

选题不确定、产品方向不确定，或者想从真实用户评论里找到高频痛点，而不是只靠脑补。

使用方式

  1. 准备合规可访问的公开评论文本和来源链接。
  2. 提取抱怨、需求、替代方案、付费意愿和高频关键词。
  3. 按选题线索、工具机会、用户画像归类。
  4. 进入内部需求池，供公众号选题、工具立项和案例复盘使用。

边界

只处理合规公开数据，不做侵入式抓取，不采集隐私信息。当前是内部 MVP，不开放自助使用。
