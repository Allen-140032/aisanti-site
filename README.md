# 三体AI空间站

`aisanti.site` 的首版静态站点。

## 页面结构

- `/` 首页
- `/cases/` 案例工坊
- `/cases/short-video-pipeline/` 公众号文章转短视频流水线案例
- `/tools/` 工具集市
- `/jiaorui/` 张佳芮的画
- `/blog/` 内容走廊
- `/about/` 关于我们

## 部署

纯静态文件，可直接部署到 GitHub Pages。自定义域名使用根目录 `CNAME`：

```text
aisanti.site
```

`aisanti.xyz` 后续注册完成后，可作为备用跳转域名。
